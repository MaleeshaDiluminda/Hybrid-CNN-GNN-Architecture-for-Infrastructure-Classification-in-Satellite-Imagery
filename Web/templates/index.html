InfraVision — What this does

InfraVision flags whether a satellite tile contains infrastructure or not. It blends a ResNet-18 backbone with a lightweight GCN head over a 7×7 feature grid, so it doesn't just see pixels — it reads context (roads next to roofs, patterns across blocks).

Why it's different

  • Context-aware: Graph message passing captures spatial relationships a plain CNN can miss.
  • Transparent: Built-in Grad-CAM shows why the model decided what it did.
  • Trustworthy scores: Calibrated probabilities (Brier/ECE) instead of raw guesses.
  • Practical: Simple Flask UI and REST endpoint for quick trials or integration.

Built with PyTorch & Flask. Trained on public land-use imagery (e.g., EuroSAT RGB) using a stratified train/val/test split and standard augmentations. Metrics include Accuracy, F1, ROC-AUC, PR-AUC, and calibration.
